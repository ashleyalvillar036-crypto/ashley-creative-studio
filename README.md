# Ashley Creative Studio

Portafolio académico de Ashley Alvillar. Curso: 4to A. Diseño Web.

## Cómo abrir el sitio sin conexión

Extraer la carpeta completa y abrir `index.html` en un navegador actual. No se necesita instalar paquetes, iniciar un servidor ni disponer de internet para el contenido principal.

## Archivos

- `index.html`: estructura HTML5 y contenido comentado por secciones.
- `style.css`: identidad visual, Grid, Flexbox y media queries a 900 y 640 px.
- `script.js`: validación local del formulario, sin envío ni almacenamiento.
- `imagenes/`: cuatro ilustraciones SVG locales con nombres descriptivos.
- `LEEME.txt`: instrucciones breves de uso.

## Navegación

Inicio, Sobre mí, Portafolio y Contacto son secciones de una sola página. Los enlaces internos apuntan a sus identificadores.

## Límites

El formulario es una demostración. Los enlaces externos abren páginas generales de comunidades profesionales y requieren internet. No representan perfiles personales de la estudiante. No hay audio, vídeo ni base de datos.
