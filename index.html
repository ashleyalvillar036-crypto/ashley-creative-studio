01 / SOBRE MÍ

Aprender.
Crear. Mejorar.

Soy Ashley Alvillar y este portafolio reúne las etapas de mi proyecto académico de diseño web. Mi objetivo es presentar el contenido de forma clara, ordenada y accesible.

Mi proceso comienza con la planificación, continúa con la estructura HTML y se completa con estilos CSS y pruebas de navegación.

Habilidades y herramientas en aprendizaje

  • HTML semántico
  • CSS
  • Diseño adaptable
  • Editor de código
  • Herramientas del navegador

02 / PORTAFOLIO

Proyectos destacados

Tres etapas de un mismo proceso creativo.

PLANIFICACIÓN

Del concepto al boceto

Definición del público, los objetivos y las secciones del portafolio: Inicio, Sobre mí, Proyectos y Contacto.

Ver objetivo y resultado

Objetivo: organizar la información antes de programar. Resultado: una estructura que guía la construcción del sitio.

HTML

Una estructura con sentido

Maquetación semántica con encabezado, navegación, contenido principal, proyectos y formulario de contacto.

Ver objetivo y resultado

Objetivo: construir una base comprensible. Resultado: secciones identificadas, enlaces internos y campos con etiquetas.

CSS Y REVISIÓN

Diseño para cada pantalla

Aplicación de colores, tipografía, cuadrículas y reglas adaptables para presentar el contenido en distintos tamaños.

Ver objetivo y resultado
